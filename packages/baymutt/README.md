# baymutt

The `baymutt` command, for [baymutt](https://baymutt.fsh.ba), a zero-knowledge secret store for
people who run coding agents. This package is
[`@baymutt/cli`](https://www.npmjs.com/package/@baymutt/cli) under its short name, at the same
version.

```sh
npx baymutt --help
npm install -g baymutt
```
